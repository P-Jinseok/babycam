# 베이비캠

폰 두 대로 쓰는 웹 아기 모니터입니다. 한쪽 폰(카메라 폰)의 영상과 소리를 다른 폰(보는 폰)에서 실시간으로 봅니다.
앱 설치 없이 브라우저로 동작하고, GitHub Pages에 올려 무료로 쓸 수 있습니다.

## 주요 기능

- 접속 코드(8자리) 또는 링크·QR로 연결, 카메라 폰에서 **허용**해야 영상 전송
- 한 번 허용한 기기는 같은 코드로 다시 접속할 때 자동 연결
- **LTE 등 서로 다른 망 지원** (TURN 중계, 아래 설정 참고)
- 연결이 끊기면 자동 재연결, 카메라 폰을 새로고침해도 같은 코드 유지
- **소리 감지 알림**: 아기 방 소리가 1초 이상 커지면 진동·알림음
- 화질 선택(절약 360p / 표준 480p / 고화질 720p), 데이터 사용량 표시
- 화면 어둡게(밤에 불빛 줄이기), 전체화면, 작은 화면(PIP), 사진 저장
- 카메라 폰 배터리·충전 상태, 연결 방식(직접/중계) 표시
- 최대 4대까지 동시 시청, 시청 중인 기기 개별 끊기

## 1. GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다. (예: `babycam`, Public)
2. 이 폴더의 파일을 **모두** 저장소 루트에 올립니다. (`lib` 폴더 포함)
3. 저장소 `Settings` → `Pages` → `Build and deployment`
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → `Save`
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속합니다.

> 카메라는 https 주소에서만 동작합니다. GitHub Pages는 https라 그대로 쓰면 됩니다.

## 2. LTE에서 쓰기 위한 TURN 설정 (권장)

같은 와이파이에서는 설정 없이 연결됩니다. 카메라 폰은 집 와이파이, 보는 폰은 LTE처럼 **서로 다른 망**이면 통신사 환경에 따라 직접 연결이 막힐 수 있어 TURN 중계 서버가 필요합니다.

**Metered 무료 TURN 사용 (가장 간단)**

1. https://dashboard.metered.ca/signup 에서 무료 가입
2. 대시보드에서 앱 이름(예: `mybabycam` → 주소 `mybabycam.metered.live`) 확인
3. `TURN Server` 메뉴에서 **API Key** 복사
4. 아래 두 방법 중 하나로 입력
   - **모든 기기에 적용**: `config.js`의 `meteredApp`, `meteredApiKey`에 입력 후 저장소에 반영
     → 가족·지인은 링크만 열면 바로 LTE 연결 가능
   - **기기별 입력**: 앱의 ⚙ 설정에 입력 (카메라 폰·보는 폰 모두 입력 권장)
5. ⚙ 설정의 **TURN 연결 테스트**로 확인합니다.
   - `항상 TURN 중계로 연결`을 켜면 같은 와이파이에서도 중계 경로를 시험해 볼 수 있습니다. 확인 후에는 끄세요.

> ⚠ `config.js`는 공개 저장소에 올라가므로 API Key가 외부에 보입니다. 다른 사람이 쓰면 무료 사용량이 줄어들 수 있습니다. 걱정되면 기기별 입력을 사용하세요.

**데이터 사용량 참고**

| 화질 | 해상도 | 시간당 대략 |
|---|---|---|
| 절약 | 360p | 0.13GB |
| 표준 | 480p | 0.3GB |
| 고화질 | 720p | 0.7GB |

- 보는 폰이 LTE면 위 양만큼 모바일 데이터를 씁니다. 오래 볼 때는 **절약**을 권장합니다.
- TURN 중계를 거치는 경우에만 Metered 사용량이 차감됩니다. 무료 제공량과 요금은 Metered 사이트에서 확인하세요.
- 직접 연결이 가능하면 자동으로 직접 연결을 먼저 씁니다. 보는 폰 화면의 `직접 연결 / TURN 중계` 표시로 확인할 수 있습니다.

## 3. 사용 방법

1. **카메라 폰**: `카메라 폰` → 카메라 선택 → `송출 시작` → 카메라·마이크 허용
2. 접속 코드를 보는 폰에 알려 주거나 `링크 공유` / `QR 코드` 사용
3. **보는 폰**: `보는 폰` → 코드 입력 → `연결` (공유받은 링크를 열면 코드가 자동 입력)
4. 카메라 폰에 뜬 요청에서 `허용`
5. 보는 폰에서 `소리 켜기`(기본 음소거), 필요하면 `소리 알림` 켜기

홈 화면에 추가하면 앱처럼 쓸 수 있습니다. (Safari: 공유 → 홈 화면에 추가 / Chrome: ⋮ → 홈 화면에 추가)

## 4. 안정적으로 쓰는 팁

**카메라 폰**
- 충전기를 연결하고, 베이비캠 화면을 **켜 둔 채** 두세요. 화면이 꺼지거나 다른 앱으로 가면 송출이 멈춥니다.
- 폰 설정에서 자동 잠금(화면 꺼짐 시간)을 `안 함` 또는 가장 길게 설정하세요.
- `화면 어둡게`를 누르면 화면이 검게 바뀌어 불빛과 배터리 소모가 줄어듭니다. (송출은 계속)
- 후면 카메라를 아기 쪽으로 두면 화질이 좋고 화면 불빛이 아기를 향하지 않습니다.

**보는 폰**
- 소리 알림은 보는 폰에서 베이비캠이 열려 있을 때 동작합니다. 화면을 꺼야 한다면 `화면 어둡게`를 쓰세요.
- Android Chrome은 `작은 화면`(PIP)으로 다른 앱을 쓰면서 볼 수 있습니다.
- 연결이 끊기면 영상이 흑백으로 바뀌고 "다시 연결하는 중"이 표시됩니다. 멈춘 화면을 실시간으로 착각하지 않도록 한 장치입니다.

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 카메라가 켜지지 않음 | https 주소인지, 브라우저의 카메라·마이크 권한 허용 여부 |
| "송출 중인 카메라 폰이 없습니다" | 코드 오타, 카메라 폰이 송출 중인지 |
| LTE에서만 연결이 안 됨 | TURN 설정 및 `TURN 연결 테스트` |
| 카메라 폰 화면이 꺼짐 | 자동 잠금 해제, 충전기 연결 |
| 소리가 안 들림 | 보는 폰에서 `소리 켜기`, 폰 무음 모드 해제 |
| 소리 알림이 너무 자주/안 울림 | `소리 알림`의 민감도 조절 (막대가 노란 선을 넘으면 감지) |

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html`, `style.css`, `app.js` | 앱 본체 |
| `config.js` | 공유용 기본 설정(TURN) |
| `lib/peerjs.min.js` | PeerJS 1.5.5 (MIT) — WebRTC 연결 |
| `lib/qrcode.js` | qrcode-generator 1.4.4 (MIT) — QR 코드 |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | 홈 화면 추가용 |

## 동작 방식과 보안

- 영상·소리는 WebRTC로 두 폰 사이에 직접(또는 TURN 경유) 전송되며 DTLS-SRTP로 암호화됩니다. TURN 서버도 내용을 볼 수 없습니다.
- 접속 코드 교환에는 PeerJS 공용 시그널링 서버를 씁니다. 이 서버는 연결 정보만 중계하고 영상은 거치지 않습니다.
- 접속 코드는 무작위 8자리이며, 카메라 폰에서 허용하기 전에는 영상이 전송되지 않습니다.
- 코드가 유출된 것 같으면 카메라 폰에서 `새 코드`를 누르세요. 기존 연결과 자동 연결 기록이 모두 초기화됩니다.
- 녹화·저장 기능은 없습니다. (보는 폰의 `사진 저장`은 그 순간의 화면만 기기에 저장)

## 한계

- PeerJS 공용 시그널링 서버는 무료 서비스라 일시적으로 접속이 안 될 수 있습니다.
- 브라우저 특성상 카메라 폰은 화면을 켜 둔 상태로 사용해야 합니다.
- 임시·보조용 도구입니다. 아기 안전을 이 앱에만 의존하지 마세요.
